🎓 Campus2Career

An Internship Finder Website connecting students with opportunities


📌 Overview

Campus2Career is a web platform designed to help students find internships effortlessly.
It bridges the gap between students seeking internships and companies offering them, making the process smooth and efficient.


✨ Key Highlights:

🔍 Search and filter internships

📝 Apply directly from the platform

👩‍💻 Student-friendly dashboard

🏢 Company portal to post internships

📊 Easy management with Flask + MongoDB backend


🖥️ Tech Stack
Frontend

HTML5, CSS3, JavaScript

Backend

Flask (Python)

REST APIs

Database

MongoDB (NoSQL)


🚀 Features

✅ User authentication (students & companies)
✅ Internship search by domain, location, or skills
✅ Profile creation for students & recruiters
✅ Internship posting & management for companies
✅ Responsive and user-friendly UI

⚡ Getting Started

Follow these steps to run the project locally:

1️⃣ Clone the repository
git clone https://github.com/your-username/Campus2Career.git
cd Campus2Career

2️⃣ Create a virtual environment
python -m venv venv
source venv/bin/activate   # Mac/Linux
venv\Scripts\activate      # Windows

3️⃣ Install dependencies
pip install -r requirements.txt

4️⃣ Run the Flask server
python app.py

5️⃣ Open in browser

Go to 👉 http://127.0.0.1:5000/
